# Sources: Judaism case study

otherwise. Reliability scores are **provisional collection tiers** (1–5),
not pack scores; rescore when a pack opens.

2. **[PRIMARY]** Targum Onkelos and other Targums — named edition required. Some vocalized or aligned texts on Sefaria are per-text licence — License: **check** / per text — PDF: not cleared until the edition header is read — Reliability (provisional): 4 once a critical or standard PD text is named; otherwise unscored — candidate, not yet reviewed

Later scholarly editions (Hayman and others) **REFERENCE-ONLY** — License: PD for named old printings; modern all-rights-reserved — PDF: PDF-OK for confirmed-PD printings only — Reliability (provisional): 3 (text historically important; many PD English editions are dated) — candidate, not yet reviewed
4. **[PRIMARY]** Alphabet of Ben Sira — Sefaria or a named PD Hebrew/English. License: **per-text, check** — PDF: PDF-OK only if that file’s licence is PD or CC-BY / CC-BY-SA — Reliability (provisional): 3 as a late narrative source, not as “biblical Lilith” — candidate, not yet reviewed
5. **[PRIMARY / finding aid]** Sefaria — https://www.sefaria.org/ — **licence is per text** (see Sefaria-Export notes in the source catalog) — PDF: never assume a blanket PDF-OK — Reliability (provisional): n/a as a platform; score the underlying work — candidate, not yet reviewed
