# Case studies

A case study is an **umbrella index** for many language packs about one
figure, name, or problem. It is not a container for packs.

Packs always live at the top level:

`/workspace/language-packs/<slug>/`

(with `pack.md`, `sources.md`, optional `raw/`, `READY`, and later
`<slug>.pdf`). This folder only points to them.

## What a case study is for
- Group the packs that belong together (for example every linguistic pack
  on the name *Yeshua*, or every primary hymn and epithet of Hecate).
- Keep a shared source list, open questions, and (where useful) an epithets
  or names table, so packs do not contradict each other.
- Stay **non-biased, historical, and linguistic**. Faith claims, later
  devotional readings, and modern occult practice are recorded as such and
  kept apart from what a given source in a given language actually says.

## Layout of each case-study folder
- `README.md`       scope, method, and how academic consensus is separated
                    from faith or practice claims
- `packs.md`        index of packs (planned, in progress, READY), each with
                    its top-level slug. **No `packs/` subdirectory.** Pack
                    folders are not created until work on that pack starts.
- `sources.md`      shared candidate and reviewed sources, with License and
                    PDF-OK / REFERENCE-ONLY flags
- `open-questions.md`
- `raw/`            optional shared notes or downloaded rights-cleared files
- other stubs as needed (for example `epithets.md` for Hecate)
