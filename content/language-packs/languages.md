# Language reference sheet

| Language | Script | Transliteration standard | Core references |
|---|---|---|---|
| Sumerian | Cuneiform | ORACC/ETCSL conventions (signs lowercase, dash-joined; Emesal noted) | ePSD2, ETCSL, CDLI, ORACC |
| Akkadian | Cuneiform | ORACC/CAD conventions | CAD (Chicago Assyrian Dictionary), CDLI, ORACC |
| Coptic | Coptic alphabet | Leipzig–Jerusalem transliteration; dialect named (Sahidic, Bohairic, etc.) | Crum, *A Coptic Dictionary*; Coptic Dictionary Online (coptic-dictionary.org); Coptic Scriptorium |
| Hebrew / Aramaic | Hebrew square script | SBL academic style | BDB, HALOT, Jastrow (rabbinic/Aramaic), Sefaria for text access |
| Arabic | Arabic script | DIN 31635 / IJMES; dialect named (Classical, MSA, Egyptian, Levantine, Gulf, Maghrebi) | Lane's *Lexicon*, Hans Wehr, al-Tabari/Qur'an corpora as relevant |
| Latin | Latin alphabet | n/a (macrons where useful) | Lewis & Short, OLD, Perseus |
| Greek (ancient/Koine) | Greek alphabet | SBL transliteration | LSJ, BDAG (Koine), Perseus, PGM editions (Betz for translation) |
| Egyptian | Hieroglyphic / hieratic / demotic | Leiden/Allen conventions | Wb, TLA (Thesaurus Linguae Aegyptiae), Faulkner |
| Ge‘ez | Ge‘ez (Ethiopic) script | standard Ethiopianist / SERA or a named scholarly scheme | Dillmann; later lexica often in copyright (REFERENCE-ONLY for recent work) |
| Syriac | Syriac (Estrangela / Serto / East Syriac) | CAL / scholarly Syriac | Payne Smith, Sokoloff; SEDRA / Beth Mardutho; Syriaca.org |
| Old Irish | Latin alphabet (Insular orthography) | standard Celticist (lenition and vowel length marked as in the named edition) | eDIL; Thurneysen; CELT (UCC — licence per text) |
| Middle Welsh | Latin alphabet | standard Welsh / Celticist | GPC; named Middle Welsh editions (licence per title); Lady Charlotte Guest is PD English, not the Welsh text |
| Gaulish | Latin, Greek, or Lepontic / Gallo-Latin script as on the object | RIG conventions | *Recueil des inscriptions gauloises* (RIG); Larzac, Chamalières; modern volumes often in copyright (check) |
| Old Norse (and runic) | Latin (manuscripts); Elder / Younger Futhark (inscriptions) | standard Old Norse (þ, ð, ǫ); runes: Rundata / Samnordisk runtextdatabas conventions | Cleasby–Vigfusson; ONP (Dictionary of Old Norse Prose); Lexicon Poeticum; Bellows 1923 and Brodeur 1916 (PD English); Rundata (licence check) |
| Old Turkic | Old Turkic runiform (Orkhon) | standard Turkological | Orkhon inscriptions; Thomsen and Radloff (often PD); later Tekin and others often REFERENCE-ONLY |
| Sakha (Yakut) | Cyrillic (modern); earlier notations vary | standard Sakha scholarly | Olonkho editions — licence per text; living-tradition sensitivity |
| Raetic | Raetic / North Italic alphabet | conventional epigraphic | modern corpora often in copyright (check). **Not the same language as Ladin** |
| Ladin | Latin alphabet (orthographies vary by valley) | the orthography of the named edition | Dolomite legend collections; Wolff copyright check (often still in copyright in life+70 jurisdictions) |
| Old East Slavic | Cyrillic | scholarly scientific transliteration (a named scheme) | Primary Chronicle editions (licence check); birch-bark letters (gramoty.ru, terms check) |
| Old Church Slavonic | Glagolitic / Cyrillic | ISO 9 or a named OCS scholarly scheme | standard grammars and dictionaries (Leskien and later; licence per title) |
| Mandaic | Mandaic script | standard Mandaic scholarly | Nöldeke; Lidzbarski (often PD, check); later Drower / Buckley often REFERENCE-ONLY |
| Sanskrit | Devanāgarī (and other Indic scripts as in the named edition) | IAST (or a named scholarly scheme); Vedic vs Classical flagged | GRETIL, MW, Cologne lexica; Griffith and other PD English with quality warnings |
| Avestan | Avestan script (and scholarly transcription) | standard Iranist (Hoffmann or a named scheme) | Geldner; Darmesteter / Mills SBE (PD check); later editions often REFERENCE-ONLY |
| Pahlavi (Middle Persian) | Pahlavi script / scholarly transcription | standard Pahlavi scholarly | West SBE (PD check); later critical editions often REFERENCE-ONLY |
| Basque | Latin alphabet (standard Basque orthography) | standard Basque / academic | folklore collections and trial records, licence per title; Aquitanian is a related ancient language, not modern Basque |
